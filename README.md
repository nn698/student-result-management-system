# student-result-management-system
The Student Result Management System is a Python-based application designed to manage student information and academic results. It allows users to register, view, search, update, and delete student records, enter and update scores for five subjects, calculate total scores, averages, and grades, and generate student report cards and class performance reports. The system uses JSON for permanent data storage, ensuring records are saved and available whenever the program is restarted. It was developed using Python programming concepts such as Object-Oriented Programming (OOP), functions, dictionaries, loops, sorting, file handling, and exception handling. To run the application, open the project folder in a terminal and execute `python main.py`.
